# 🌍 Younique Travel

> **Designed for those who don't just travel, they experience. **

Younique Travel is a modern and responsive tourism website designed to inspire users to explore destinations and discover new travel experiences. Built from scratch using **HTML5, CSS3, and JavaScript**, the project combines an engaging visual design with interactive web functionality.

## ✨ About the Project

Younique Travel was developed as a second-year Computer Science web development project, with a focus on creating an attractive, intuitive, and responsive tourism experience.

The project allowed me to apply front-end development concepts in a practical environment, from structuring web pages and creating responsive layouts to implementing interactive features with JavaScript.

## 🚀 Key Features

- 🌍 Destination-focused tourism experience
- 📱 Responsive design for different screen sizes
- 🧭 Intuitive navigation and user-friendly interface
- ✨ Interactive elements powered by JavaScript
- 🖼️ Visual presentation of travel destinations
- 🎨 Modern and engaging front-end design
- ⚡ Lightweight front-end implementation

## 🛠️ Technologies

| Technology          | Purpose |
|------------         |---------|
| **HTML5**           | Website structure and content |
| **CSS3**            | Styling, layouts and responsive design |
| **JavaScript**      | Interactive functionality and dynamic behavior |

## 🎯 Project Objectives

The main objectives of this project were to:

- Develop a complete website from scratch
- Strengthen front-end development skills
- Apply HTML, CSS and JavaScript concepts in a practical project
- Create a responsive and accessible user interface
- Improve understanding of user experience and web design
- Build a project suitable for a professional development portfolio
